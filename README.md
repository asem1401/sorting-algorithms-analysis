# Sorting Algorithms Analysis

A Java project implementing and analyzing classical sorting and selection algorithms. The project compares algorithm performance and collects execution metrics.

## Features

- Quick Sort implementation
- Merge Sort implementation
- Deterministic Select algorithm
- Sorting verification
- Performance metrics export (CSV)

## Technologies

- Java
- Git
- CSV

## Project Structure

```
src/
├── quickSorting.java
├── mergeSorting.java
├── DeterministicSelect.java
├── SortVerification.java
└── Main.java
```

## Purpose

This project was developed to study algorithm efficiency and compare the performance of different sorting techniques.
